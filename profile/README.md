## kenno demo

A small product and its team, for showing [kenno](https://kenno.ai) end to end.

**[feedback-board](https://github.com/kenno-demo/feedback-board)** is a public board where people suggest features and vote on them. The team plans each feature in kenno, Claude Code builds it, and the plan keeps who decided what and why: the versions people suggested, the questions the agent asked and their answers, the progress reports and the pull requests.

Everything here is reset before each demo.
